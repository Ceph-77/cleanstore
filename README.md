# CleanStore

Application web pour l'industrie du nettoyage de magasins.

## Portée (à confirmer/détailler avec l'utilisateur)

- **Gestion de tâches/horaires** — planifier, assigner et suivre les tâches de nettoyage par magasin/employé
- **Suivi de conformité/inspection** — checklists, photos avant/après, rapports de qualité pour audits
- **Gestion d'inventaire produits** — suivi des produits/équipements de nettoyage, commandes, stock

## Plateforme

Web (navigateur), utilisable sur PC et mobile.

## Structure

- `frontend/` — interface web
- `backend/` — API et logique métier
- `docs/` — spécifications, notes de conception
